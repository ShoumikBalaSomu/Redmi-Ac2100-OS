# NexRouter v2.0 — Noop Elimination & Kernel/Driver Recreation Audit

This document records every noop, broken script, and architectural contradiction found in the v1.0 repository and details the engineering fixes implemented in **NexRouter v2.0.0**.

---

## 1. Summary of Eliminated v1.0 Noops & Bugs

| # | Component | v1.0 Defect / Noop | v2.0 Engineering Fix |
|---|---|---|---|
| **1** | `99-nexrouter-firstboot` (`mt7615e` MU-MIMO) | Set `beamformer='1'`, `mu_beamformer='1'`, `short_gi='1'`, `rts_threshold='2346'`, and `amsdu='0'`. Upstream `mt7615e` reports VHT capability `0x338001f8` (Bits 11 & 19 = `0`), so `mac80211.sh` silently stripped `[SU-BEAMFORMER]` and `[MU-BEAMFORMER]`. Moreover, `short_gi` and `rts_threshold` are invalid UCI keys, and `amsdu='0'` disabled aggregation. | Added `patches/mt76/201-mt7615-vht-beamformer-capability-and-sounding.patch` to advertise VHT SU/MU Beamformer & 4-stream sounding dimensions in `mt7615/init.c`, and updated `99-nexrouter-firstboot` to use valid `mac80211` UCI keys (`short_gi_80`, `su_beamformer`, `mu_beamformer`, `rts`, `tx_queue_data2_burst`). |
| **2** | `patches/` (Kernel, DTS & `mt76` C code) | Zero kernel or driver patches existed in the repo (`analysis/upstream/` held unmodified copies of upstream DTS files never used by the build). | Created `patches/kernel-6.6/` (PCIe ASPM disable on `pcie0`/`pcie1`, hardware watchdog enable, `MTK_DMA_SIZE` 256→512 ring expansion, PPE timeout tuning) and `patches/mt76/` (default Threaded NAPI `napi_dev.threaded = 1` + VHT TxBF capability flag exposure) plus `build/build-from-source.sh`. |
| **3** | `nexrouter-smp` vs `nexrouter-core` | Two separate init scripts ran at `START=98` and `START=99`. `nexrouter-smp` hardcoded IRQ numbers `19`, `27`, `28` (wrong on Kernel 6.6/6.18) and set `rps_cpus=e` and `rps_sock_flow_entries=32768`; 1 second later `nexrouter-core` overwrote `rps_cpus=f` and `rps_sock_flow_entries=4096`. | Removed `nexrouter-smp` and unified all tuning into `nexrouter-core` (`START=98`), dynamically matching PCIe/GMAC IRQs across all 4 MIPS 1004Kc VPEs (`VPE0`: GMAC, `VPE1`: MT7603E 2.4G, `VPE2`: MT7615N 5G, `VPE3`: RPS/Threaded NAPI). |
| **4** | `20-rrm-neighbor-sync` & `farlink-daemon` | Hardcoded `9c:9d:7e:18:c4:56` and `9c:9d:7e:18:c4:57` (the MAC addresses of one physical router). On any other Redmi AC2100 unit, 802.11k/v steering advertised a nonexistent BSSID. | Rewrote both scripts to dynamically query live BSSIDs, SSIDs, frequencies, and RRM strings from `ubus call hostapd.*` and `/sys/class/net/*/address`. |
| **5** | `99-nexrouter.conf` & `20-nexrouter-qdisc` | Configured `nf_conntrack_max=65536`, 8 MiB TCP socket buffers (`rmem_max=8388608`), and 32 MiB `fq_codel` memory limit on a 128 MiB RAM board—risking kernel OOM kills under heavy load. | Right-sized for 128 MiB DDR3: `nf_conntrack_max=16384`, 2 MiB max TCP socket buffers, and 4 MiB `fq_codel` cap, plus AQL (`aql_txq_limit = 2000` µs) per-AC airtime limits. |
| **6** | `99-nexrouter-firstboot` (WAN PPPoE) | Unconditionally overwrote `network.wan.proto='pppoe'` with literal `'your_pppoe_username'`, breaking DHCP WAN out of the box. | Preserves OpenWrt's default DHCP WAN out of the box so WAN works immediately after flashing. |
| **7** | `repack-mtk-firmware.sh` (`l1profile.dat` EEPROM) | Truncated `INDEX1_EEPROM_size=0x4000` instead of `0x4DA8`, cutting off 3,496 bytes of MT7615 5 GHz factory TxBF/MU-MIMO calibration data, and used `sed -i` which silently nooped when keys were missing. | Restored full `INDEX1_EEPROM_size=0x4DA8`, added deterministic `upsert_dat_key` function, enabled `WHNAT=1`, and added system `unsquashfs`/`mksquashfs` discovery. |
| **8** | Duplicate `build/files/www/nex/` tree | Tracked a duplicate copy of `webui/src/` inside `build/files/www/nex/` and duplicated sysctl/qdisc files inside `99-nexrouter-firstboot`. | Single source of truth: `webui/src/` is validated and built into `/www/nex/` at build time, and `/etc/sysctl.d/99-nexrouter.conf` + `/etc/hotplug.d/iface/20-nexrouter-qdisc` live only in `build/files/etc/`. |
| **9** | `webui/src/js/panels.js` (`panelOverview` crash) | `coreCanvas` was never declared in `panelOverview` and its `ref` callback was left as `/* coreBars target */`, throwing `ReferenceError: coreCanvas is not defined` on every refresh before System/Radios rendered. | Declared `coreCanvas` and bound `ref: (el) => { coreCanvas = el; }` so the Overview panel renders per-core bars, System info, and Radios without crashing. |
| **10** | `rpcd/nexrouter` (`/proc/stat` & `packet_steering`) | `method_performance` returned single-sample cumulative CPU ticks since boot instead of a live delta, and `jbool` reported `packet_steering='2'` as `false`. | Implemented stateful `/tmp/nexrouter_stat.prev` delta calculation for instantaneous live per-VPE CPU load and updated `jbool` to recognize `2`. |
